Media Organizer Application
===========================

System Requirements:
-------------------
- Operating System: Windows 10 or 11.
- No additional software is required to run the executable (.exe) version.
- (Optional) If running from source code: Python 3.8+ and Tkinter are required.

How to Run the Program:
-----------------------
1. Navigate to the folder containing "MyFileOrganizer.exe".
2. Double-click "MyFileOrganizer.exe" to launch the application.
   (Note: Ensure "app_icon.ico" is in the same folder for the icon to display correctly).
3. The main window will appear titled "Media Organizer".
4. Click on the "Select Folder to Sort" button.
5. A dialog box will open. Browse and select the folder containing your unsorted images and videos.
6. The program will automatically create two new folders inside your selected directory:
   - "Images_Sorted": Contains all moved image files.
   - "Videos_Sorted": Contains all moved video files.
7. A message box will appear confirming the number of files moved.

Supported Formats:
------------------
- Images: .jpg, .jpeg, .png, .gif, .bmp, .tiff, .webp, .heic, .svg
- Videos: .mp4, .mov, .avi, .mkv, .wmv, .flv, .webm, .m4v
